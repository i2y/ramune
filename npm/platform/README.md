# @ramune platform binary

This package ships a prebuilt `ramune` CLI binary for a single OS / CPU combination. It is resolved automatically as an optional dependency of the top-level [`ramune`](https://www.npmjs.com/package/ramune) package.

You almost certainly want to install `ramune` instead:

```
npm install -g ramune
```

Project homepage: https://github.com/i2y/ramune
