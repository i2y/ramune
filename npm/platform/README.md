# @ramune platform binary

This package ships a prebuilt `ramune` CLI binary for a single OS / CPU combination. It is resolved automatically as an optional dependency of the top-level [`@ramunejs/cli`](https://www.npmjs.com/package/@ramunejs/cli) package.

You almost certainly want to install `@ramunejs/cli` instead:

```
npm install -g @ramunejs/cli
```

Project homepage: https://github.com/i2y/ramune
